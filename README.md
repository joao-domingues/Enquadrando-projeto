# Enquadrando – Data Scraping & Media Automation

Projeto em Python voltado à automação da coleta, tratamento e integração de dados provenientes de múltiplas fontes externas, como Letterboxd, Spotify e TMDB. O sistema realiza web scraping e consumo de APIs públicas para estruturar informações originalmente não organizadas, gerando arquivos CSV e realizando o download automático de mídias associadas, como QR codes e pôsteres.

O projeto foi desenvolvido utilizando Python com apoio das bibliotecas Pandas, NumPy, BeautifulSoup e Spotipy, além da integração com a API do The Movie Database (TMDB). A aplicação demonstra domínio de conceitos como web scraping, consumo de APIs REST, tratamento e persistência de dados, automação de processos e integração entre sistemas distintos.

Como resultado, foi implementado um pipeline automatizado capaz de transformar dados não estruturados da web em bases organizadas, prontas para uso em análises, visualizações, dashboards ou integração com outras aplicações.
